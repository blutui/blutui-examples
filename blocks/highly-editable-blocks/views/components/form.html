Variables: handle — 'contact' or 'newsletter' submit_label — button text hide_labels — true to rely on placeholders instead of labels columns — 1 or 2 IMPORTANT: the {% form %} tag only accepts a *literal* string handle. Passing a variable is a compile-time error that 500s the page — and inside a Canopy block it makes the whole section render blank. So each supported form gets its own branch below.
